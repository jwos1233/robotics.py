# Dashboard

`dashboard.html` is a **static snapshot** generated from the database, not a live
view. It exists so the data can be looked at before the production frontend is
built, and it is regenerated by re-running the export.

## What it shows

- **Origin share of US roller screw imports**, annual, from 39 months of Census
  data. The headline finding: Japan fell from 46.9% to 30.2% of tracked origins
  between 2023 and 2026 H1 while Switzerland roughly doubled.
- **US against EU**, both indexed to a common base on a 3-month trailing mean.
  Deliberately one axis and never blended — divergence between the two
  jurisdictions is the signal.
- **The quantity break at 2024-11**, shown on the Japan series because that is
  the series the claim is about: value held steady while reported unit count
  fell 66,421 → 4,796.
- **The constraint map**, with a dot per node showing whether data is flowing,
  a series is registered, or no source exists yet.
- **Equity baskets**, all reporting 0 priced, because no provider is confirmed.
- **Taiwan disclosed revenue**, constraint-side rather than in a basket.

## What it deliberately does not show

- No severity score or break-point tier on any node.
- No unit-value or ASP chart. The unit value on this tariff line is not a price
  series, and plotting it as one would be the single most misleading thing the
  dashboard could do.
- No partial basket returns.

## Regenerating

The generator reads the database and injects JSON into the template:

```
python -m robotics_radar.scheduler.backfill census --from 2023-01 --to 2026-06
python -m robotics_radar.scheduler.backfill comext --from 2023-01 --to 2026-06
python -m robotics_radar.scheduler.run twse_revenue
# then re-run the export/inject step used to build dashboard.html
```

## Next step: make it live

This snapshot is the design proof. The production version should be served by
the FastAPI app off the same endpoints the API already exposes, so the page
updates when the scheduler runs rather than when someone regenerates a file.
The charts and layout carry over unchanged; only the data source moves from an
embedded blob to `fetch()`.
